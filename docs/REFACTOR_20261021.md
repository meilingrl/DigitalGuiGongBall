## 设计选择

选择模块重构：保留有用的状态机和渲染算法，重写其边界。只修类型和 try/catch 会留下三维测试耦合；替换整套技术栈则没有对应收益。

四个可独立验证的增量按序执行。事务命令边界暂缓：现有路由已在事务内调用，且本轮没有新增调用入口；不为将来的未知用例铺框架。类型引用环可随稳定 ID 规格归一一并解除。
